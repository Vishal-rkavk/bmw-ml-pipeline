# Results Summary

Reported run: **2026-11-04**. The numbers below come from
`artifacts/eval/results.json`, `artifacts/logs/train_v2.log`,
`artifacts/logs/evaluate_v2.log`, `artifacts/logs/generate_v2.log`, and the
resume demo logs in `demo-artifacts/logs/`. Small copies are kept under
[`docs/evidence/`](evidence/).

## Data

| | |
|---|---|
| Corpus | **1,000** English-language BMW Group newsroom articles (BMW, MINI, Rolls-Royce, Motorrad) |
| Date range | 2024-05-24 – 2026-11-04 (collector cutoff: 2023-01-01) |
| Rejected URLs | 60 sitemap URLs cached as `not_article` |
| Split (hash-based) | **800 train / 200 eval** documents |
| Tokens | **1,069,056 train** (2,088 blocks x 512) / **279,040 eval** (545 blocks x 512) |
| Text size | Median article 4,817 chars; train split 4.43M chars, eval split 1.16M chars |
| Collection re-run | ~1 s no-op at the 1,000-doc target (no duplicates created) |



## Training

| | |
|---|---|
| Model | SmolLM2-360M (pinned revision `f8027fd0`), full fine-tune |
| Settings | 512-token blocks, batch 16, AdamW lr 1e-4, linear warmup/decay, bf16 |
| Schedule | 130 steps/epoch; 800 steps ≈ 6.2 epochs |
| Speed | 0.23 s/step, ~35–36k tokens/s (A100) |
| Checkpoints | every 50 steps, ~4.1 GB each (model + optimizer states), atomic save in ~2.6 s, last 2 kept |
| Loss | 2.780 (step 10) → **1.043** (step 800) |
| Final model | **800 steps**, trained from scratch; exported to `artifacts/model/` (~1.4 GB) |

## Evaluation (held-out perplexity)

| Phase | Loss | Perplexity |
|---|---|---|
| before (base SmolLM2-360M) | 2.8200 | **16.78** |
| after (fine-tuned) | 2.4762 | **11.90** |

**Perplexity dropped 29.1% on documents the model never saw in training.**

Honest nuance: train loss (~1.04) is much lower than eval loss (~2.48) —
after ~6 epochs the model partially memorizes the training set.

## Generations

`docs/evidence/generations.md` holds 12 prompts, each generated by the
fine-tuned and the base model with identical seeds. The fine-tuned model
reproduces press-release style ("Munich." datelines, corporate diction like
"technology-open approach and global footprint"), while the base model
produces generic or off-domain text.
